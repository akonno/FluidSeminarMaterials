計算領域は十分広いか

外部流れの計算領域は、どこまで広く取ればよいのだろうか。実際の物体まわりの流れは遠くまで続くが、計算機上では有限の領域を決め、その端に境界条件を置く必要がある。境界が物体に近すぎると、境界条件の影響が物体まわりの流れに伝わる。一方、領域を広げるとセル数が増え、計算の負担も大きくなる。

cavityの検証ページでは、格子解像度と計算時間が結果に与える影響を確認した。ここでは、正方形柱まわりの非定常流を例に、計算領域の大きさを変えたときに流れと力の統計量がどう変わるかを見る。

このページの位置づけ

ここでは、計算領域の大きさが解に与える影響を理解するため、実際の演習で求める内容より詳しいdomain sensitivity studyを紹介しています。複数domainの系統比較、CdC_dCd​・ClC_lCl​ RMS・Strouhal数の詳細比較、位相をそろえたwakeの比較、周期状態の定量判定を、演習のたびにすべて行う必要はありません。 実際の演習では、指定された条件で計算し、結果を確認・考察することが中心です。このページは、なぜ計算領域の大きさを気にする必要があるのかを理解するための補足・発展的な教材です。

このページの計算について

図と数値はOpenFOAM Foundation 14で実施した教材用計算から作成した。このページは結果と検証の考え方を紹介するもので、OpenFOAM caseやraw計算結果はこの教材repositoryに含めていない。

計算条件と比較方法¶

正方形柱の一辺を代表長さ DDD、入口速度を U∞U_\inftyU∞​、動粘度を ν\nuν とすると、今回の条件は次のとおりである。

項目条件
Reynolds数 Re=U∞D/νRe=U_\infty D/\nuRe=U∞​D/ν100
正方形柱の一辺 DDD1 m
入口速度 U∞U_\inftyU∞​1 m/s
動粘度 ν\nuν0.01 m²/s
無次元時間 t∗=tU∞/Dt^*=tU_\infty/Dt∗=tU∞​/Dt∗=tt^*=tt∗=t

計算は2次元・層流の非定常計算で、OpenFOAM Foundation 14のfoamRunとincompressibleFluidを用いた。正方形柱はno-slip、上下の遠方境界はsymmetryPlane、厚さ方向は1セルのemptyである。渦放出を始めるきっかけとして、全caseに入口速度の0.1%にあたる 0.001 m/sの横方向速度摂動を同じ位置に与えている。

領域の感度を比べるdomain sweepでは、正方形柱の近くと後流のcore meshを N=24N=24N=24 cells/DDD で固定し、上流距離、下流距離、半幅のうち一つだけを変えた。全caseで Δt=0.005\Delta t=0.005Δt=0.005 sとし、最大Courant数は0.5未満であった。力の統計量は、各caseで周期状態に達した後の5周期から求めた。

計算領域の寸法¶

ここで使う寸法を図に示す。

  • DDD：正方形柱の一辺

  • LuL_uLu​：柱の上流側の面から入口までの距離

  • LdL_dLd​：柱の下流側の面から出口までの距離

  • HHH：柱の中心線から上端または下端境界までの距離

したがって、上下境界間の全幅は 2H2H2H である。たとえば H/D=10H/D=10H/D=10 は、柱の中心から上にも下にもそれぞれ 10D10D10D、全幅では 20D20D20D を意味する。

横方向境界までの距離¶

上下境界が近いと、流れが通り抜ける幅が狭くなる。このような影響をconfinement（閉じ込め）またはblockageとして考える。ここではblockage比を β=D/(2H)\beta=D/(2H)β=D/(2H) と定義する。H/DH/DH/Dが小さいほど、柱の幅に対して上下境界間の幅が狭い。

以下は Lu/D=10L_u/D=10Lu​/D=10、Ld/D=20L_d/D=20Ld​/D=20 を固定し、H/DH/DH/Dだけを変えた結果である。各セルには基準値と、同じ条件の H/D=10H/D=10H/D=10 に対する変化率を示す。

3（0.167）1.84992（+22.85%）0.24199（+24.23%）0.17265（+18.21%）
5（0.100）1.60358（+6.49%）0.19992（+2.64%）0.15387（+5.35%）
10（0.050）1.50584（基準）0.19478（基準）0.14605（基準）
15（0.033）1.49410（−0.78%）0.19495（+0.09%）0.14501（−0.71%）

ここで CdC_dCd​ は抗力係数、ClC_lCl​ は揚力係数、St=fD/U∞St=fD/U_\inftySt=fD/U∞​ はStrouhal数である。H/D=3H/D=3H/D=3では3つの指標すべてが基準から大きく変わり、H/D=5H/D=5H/D=5でも差が残る。一方、H/D=10H/D=10H/D=10と15の主要指標はおよそ1%以内であった。この計算条件では、上下境界が近いことによるconfinementが解に影響している。

非定常流を同じ位相で比べる¶

カルマン渦が放出される非定常流では、同じ時刻の図を並べても、caseごとに渦放出の位相（phase）がずれていることがある。その場合、同じ時刻の比較が、異なる流れの段階を比べることになってしまう。

そこでこのstudyでは、各caseで揚力係数 ClC_lCl​ が正の最大値になる位相を基準にwake snapshotをそろえた。渦度は0.5秒ごとに保存した場の間を補間している。図には横方向が狭いcase、上流または下流を短くしたcase、基準caseを示す。実際のsnapshot時刻は異なるが、渦放出のcycle内で同じ段階を比べやすくなる。

実線は正、破線は負の無次元渦度を示す。図をクリックするとSVGを拡大できる。

周期状態と計算コスト¶

この流れは時間とともに変化し続けるため、最終的に速度場が一定になる「定常状態」を待つ問題ではない。周期状態（limit cycle）が安定したかを確認する。今回の判定では、最後の5周期とその前の5周期を比べ、平均 CdC_dCd​、ClC_lCl​ RMS、ClC_lCl​ のpeak-to-peak振幅、StStSt の変化がそれぞれ2%以内であることを条件とした。

基準caseの力係数の履歴では、揚力振動が成長した後に、統計を取った最後の5周期の範囲で振幅がほぼ安定している。

基準caseの力係数と統計区間。図をクリックするとSVGを拡大できる。

計算領域を広げると、一般にセル数が増える。今回のdomain sweepではセル数は21,456から31,656であった。多くのcaseは40,000 time stepsまで計算し、Ld/D=5L_d/D=5Ld​/D=5は周期判定のため50,000 stepsを要した。wall-clock timeは同時に走る計算負荷にも左右されるため、ここではセル数とstep数を計算コストの目安にする。

格子依存性との区別¶

domain sweepでは、領域の大きさ以外をそろえるため、柱近くと後流のcore meshを N=24N=24N=24 cells/DDD に固定した。ただし、これは格子収束した解を使ったという意味ではない。baseline meshで得られた値を次に示す。

N=16N=16N=16から24へ変えると ClC_lCl​ RMS は約8.6%変化した。したがって、N=24N=24N=24は領域サイズだけを比較するために固定した格子であり、grid-converged reference（格子収束した基準解）ではない。ここで分かるのは、同じ N=24N=24N=24 の離散化条件で計算領域を変えたときに、解がどの程度変化するかである。

まとめ¶

境界を物体に近づけすぎると、流れ場だけでなく平均抗力、揚力変動、渦放出周波数も変化する。今回の Re=100Re=100Re=100 正方形柱計算では、上下境界までそれぞれ 10D10D10D（全幅 20D20D20D）、上流 10D10D10D、下流 10D10D10D 程度まで広げると、それより広い領域にしたときの主要指標の差は小さかった。

ただし、これは今回の格子、境界条件、数値手法で得られた傾向であり、他の計算に一律に適用できる推奨値ではない。必要な領域の広さは流れの条件、格子、境界条件、数値手法に応じて確かめる。
