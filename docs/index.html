この教材について¶

このサイトは、工学院大学 工学部機械工学科 機械工学セミナー（流体工学セミナー）の一部で使用している 教材の一部を整理・公開したものである。

本教材は、セミナー全体を網羅するものではない。 現在は主に、Pythonプログラミング、Linux / UNIX操作、数値流体解析という独立した教材群を掲載している。 各教材群はそれぞれ異なる目的と構成を持ち、必要な部分だけを参照して利用することも想定している。

Pythonプログラミング教材の目的は、 プログラミングの文法や知識を網羅的に学ぶことや、 完成度の高い作品を作ることではない。 それよりも、

  • 自分で考えて試すこと

  • 少しずつ動かしながら理解を深めること

  • 分からないところで立ち止まり、調べたり試したりすること

を通して、プログラミングを「考えるための道具」として使い始めることを重視している。

なおこの教材では、if文やfor文、関数定義（def）といった Pythonの基本的な文法要素を体系的に解説していない。 これらは、1年次に学んだVBAや、MATLABなどで扱ってきた考え方と共通する部分が多く、 書き方の違いについては、必要に応じて調べながら使っていけばよい。

分からない文法や書き方が出てきた場合には、 エラーメッセージや実行結果を手がかりにしつつ、 公式ドキュメントや解説資料を参照しながら理解してほしい。

この教材は、最初からすべてを完全に理解することを前提にしたものではない。 各段階で提示される内容や課題には真剣に取り組んでほしいが、 その時点ですべてを理解しきれていなくても構わない。

後の教材で同じ考え方や仕組みに再び触れることで、 「ああ、こういうことだったのか」と理解が深まることだろう。

このサイトで扱う教材¶

Pythonプログラミング¶

Pythonプログラミング教材では、授業回ではなく、内容や概念のまとまりをもとに、次の内容を扱う。

  • 環境準備

    • MiniforgeおよびJupyterLabを用いて、Pythonプログラムを実行・試行するための環境を整える。

  • 短い問題を通した試行練習

    • KodingBasicsを用いて、小さな問題に対して「考えて書き、動かして確かめる」経験を積む。

  • 問題を分解して考える練習

    • ハノイの塔を題材に、複雑な作業を小さな手順に分けて考える方法を学ぶ。

  • 画面上で動くものを作る

    • pygame-ceを用いて、図形描画、入力、アニメーション、運動や衝突を扱う。

    • ゲーム制作だけでなく、動きやシミュレーションを考える入口として利用する。

  • 自由制作

    • それまでに扱った要素をもとに、作成・改良・振り返りなどを行い、学習内容を整理する。

Linux / UNIX操作¶

Linux / UNIX操作教材では、Windows上のWSLとUbuntuを使い、Linuxのコマンドライン、Windowsとのファイル連携、WSLgのGUI確認、UBXを使ったコマンド練習を扱う。Linux環境の準備から基本操作、UBXの設定と演習へ進む構成である。

数値流体解析¶

数値流体解析教材では、Windows上のblueCFD-Coreを利用してOpenFOAMによる計算を行い、ParaViewで結果を可視化する。cavityを使った基礎的な計算から始め、meshやboundary conditionの設定、2次元外部流れ、3次元外部流れ、自由形状を使った解析へ進む構成である。

Note

数値流体解析教材は、従来使用してきた教材から現在移行・再構成中である。現時点では、旧教材に含まれていたすべての説明、図、操作手順を本サイトへ移行できていない。特に一部のインストール手順や操作説明は、公開可能な形への再整理が未完了である。そのため、現時点の数値流体解析教材だけで授業内のすべての作業を完結できるとは限らない。授業で使用する場合は、必要に応じて教員の指示や別途配布資料も参照すること。

各教材群は独立して利用できる。すべてを同じ順番で学ぶ必要はなく、授業や演習の目的に応じて必要な章を参照してよい。

各教材には、その時点で取り組むべき課題が含まれている。課題には真剣に取り組んでほしいが、すべてを完全に理解してから次へ進む必要はない。

この教材の読み進め方¶

この教材は、講義資料として読むことよりも、 実際に手を動かしながら理解を深めることを前提としている。

各ページには、説明、例題、演習課題、提出を求める課題などが含まれている。課題が提示されている場合には、その時点で扱っている内容を踏まえ、自分なりに考え、試しながら取り組むことが重要である。

Pythonプログラミング教材は、環境準備から短い問題、問題分解、pygame-ce、自由制作へと、概ね順番に進むことを想定している。ただし、すべてを完全に理解してから次に進む必要はない。

Linux / UNIX操作教材は、WSLの導入から順に進めるほか、目的に応じて基本コマンド、Windowsとの連携、UBXの各章を参照できる。

数値流体解析教材は、blueCFD-Coreの導入やcavityから順に進めてもよいが、授業や目的に応じて必要な章だけを参照することも想定している。

プログラムは、最初からきれいに書く必要はない。 まずは動かしてみて、結果を確認し、 うまくいかない点を修正しながら理解を深めていくことを想定している。

一方で、すべてのコードや仕組みをその場で完全に理解することまでは求めていない。 課題に取り組む中で生じた疑問や引っかかりは、 後の教材で同じ考え方に再び触れることで、徐々に整理されていくだろう。

分からない点があれば、そのままにせず、 資料を読み返したり、コードを動かし直したりすることが重要である。 必要に応じて、周囲と相談したり、質問したりしてよい。

教材内の表示について¶

この教材では、説明や課題の種類を区別するために、以下のような表示を用いている。

ポイント

「ポイント」は特にプログラムの説明に使われている．

演習課題

「演習課題」は実際にプログラムを書いて試してみてほしい課題を記載している．ただし提出を求めている課題ではない．

課題

「課題」（演習課題ではない）は提出を求めている課題である．

教材の公開と更新について¶

本教材は、GitHub Pages上で公開している。 授業で実際に使用している教材のうち、 Pythonプログラミング、Linux / UNIX操作、数値流体解析に関する部分を整理・公開している。

教材の大枠となる構成や内容は整っているが、 授業実践を踏まえて作成・拡張してきた経緯もあり、

  • 説明の順序が前後している部分

  • 区切りが分かりにくい箇所

  • 補足が不足している箇所

が残っている。 これらについては、授業実践を踏まえながら、 順次整理・修正・補足を行っていく予定である。
