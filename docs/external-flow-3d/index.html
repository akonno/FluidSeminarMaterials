与えられた車両形状による3次元外部流れ

配布された車両形状を使って、3次元外部流れのメッシュ生成、計算、可視化を行う。caseはOpenFOAM演習case repositoryのRelease Assetから取得する。

Caseを入手する¶

vehicle caseは、前の「cavityを実行して可視化する」の章でダウンロードしたOpenFOAM-exercises-2026.1.zipに含まれている。すでにダウンロード・展開している場合は、その中のvehicleを使えばよく、再ダウンロードは不要である。

まだ入手していない場合は、次のReleaseから取得する。

OpenFOAM-exercises v2026.1 Release

OpenFOAM-exercises-2026.1.zip

GitHubが自動生成するSource code (zip)は学生用case packageではない。Release AssetのOpenFOAM-exercises-2026.1.zipを使用する。Releaseページが404になる場合は、「cavityを実行して可視化する」の章にある注意事項を確認する。

以下の操作は、ZIPを展開したディレクトリでblueCFD-Core terminalを開いて実行する。

STLを準備する¶

計算前に、vehicle/model/にあるSTLをcaseが読むconstant/geometry/STLObject.stlへコピーする。

cd vehicle
cp model/concept_car_038-mod.stl constant/geometry/STLObject.stl

車両モデルの出典は、case repositoryのvehicle/model/README.mdに記録されている。

この節で扱うモデルと図のprovenanceは次のとおりである。

  • Model: FREE Concept Car 038 - public domain (CC0)

  • Source: Sketchfab

  • Visualization / CFD: Akihisa KonnoがParaView / OpenFOAMで作成

Allrunを実行する¶

./Allrun

既存の計算結果を消して最初から実行する場合は、./Allcleanを実行してから./Allrunを実行する。Allcleanは、コピーしたconstant/geometry/STLObject.stlを削除しない。

Allrunは、概ね次の処理を行う。

  1. blockMeshで背景メッシュを作る。

  2. decomposeParで並列計算用に分割する。

  3. snappyHexMeshでSTL形状を含むメッシュを生成する。

  4. renumberMesh、potentialFoamを実行する。

  5. foamRunを並列実行する。

  6. reconstructParで結果を再構成する。

このcaseは小さなcavityより計算時間とメモリを必要とする。実測では、対象環境で4並列のfull workflowが約16分23秒で完了したが、学生PCによって大きく異なる。

ParaViewで確認する¶

paraFoamで結果を開き、必要に応じてMesh RegionsでinternalMeshを非表示にする。車両表面、床、出口などのregionを選び、圧力場や断面の速度ベクトルを表示する。

最終時刻のUとp、力、streamline、cut-planeなどのfunction-object出力を確認する。設定と出力の詳細はcase repositoryのVALIDATION.mdを参照する。

課題¶

3次元車両まわり流れを計算し、次を含む可視化結果をレポートする。

  • 車両表面の圧力場

  • 適切な断面の速度ベクトル

  • 使用したcase、計算条件、メッシュの概要

  • 計算に要した時間と、計算上の注意点

提出方法と期限はKU-LMSで確認する。
