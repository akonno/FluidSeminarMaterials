指定形状まわりの2次元外部流れ

この課題では、自分で決めた2次元形状を方眼紙などで設計し、blockMeshで流体領域を定義して物体まわりの流れを解析する。実行可能なcaseは、課題条件に合わせて自分で作成する。

課題の位置づけ¶

前章の角柱まわり流れでは、配布されたchannel caseを土台に8ブロックのメッシュと境界条件を設計する。ここではその考え方を発展させ、単純な直方体などを避け、自分で決めた2次元形状を流体領域の中に配置する。

方眼紙で形状を設計する¶

次の順に設計する。

  1. 物体の輪郭と流れの向きを決める。

  2. 物体の周囲を複数のblockへ分割する。

  3. 各blockのverticesと分割数を決める。

  4. inlet、outlet、wall、frontAndBackをpatchとして分類する。

  5. 0/U、0/p、systemの設定を整合させる。

blockMeshを実行したら、まずメッシュの形と境界patchをParaViewで確認する。その後に流れを計算し、圧力や速度場を可視化する。

形状設計と解析結果の例¶

以下に、3つの障害物を配置した形状について、方眼紙によるブロック配置の設計から、メッシュ生成、流れ解析、可視化までの例を示す。これは作成例の一つであり、課題では各自で形状とブロック配置を考えること。

解析の実行¶

前章「blockMeshと境界条件」でchannelから作成したsquare-cylinder caseを、新しい形状用にコピーする。square-cylinderは配布caseではなく、前章で作成した作業用caseである。square-cylinderがあるディレクトリで、元のcaseを残したまま別名のcaseを作る。ここでは新しいcase名をcustom-shapeとする。

cp -r square-cylinder custom-shape
cd custom-shape

OpenFOAMは、計算結果をcaseディレクトリ内の時刻名のディレクトリに保存する。例えば0.1/には時刻0.1、0.2/には時刻0.2のUやpなどが保存され、paraFoamはこれらを読み込んで可視化する。実際に作られる時刻ディレクトリはsystem/controlDictの出力設定によって異なる。

新しい形状を時刻0から計算する場合は、まず操作場所がコピー先のcustom-shapeであることを確認する。そのうえで、custom-shape内にある0/以外の数値名の計算結果ディレクトリ（例えば0.1/、0.2/）をすべて削除する。元のsquare-cylinderには手を加えない。初期条件の0/と、物性値・メッシュを置くconstant/、計算条件を置くsystem/は削除しない。さらに、system/controlDictを次の設定にする。

startFrom   startTime;
startTime   0;

コピーしたcaseのsystem/blockMeshDictを、方眼紙で設計した形状に合わせて編集する。頂点座標、blockの配置、各blockのセル分割数、境界面を設定する。0/U、0/pなどの境界条件も確認・調整し、blockMeshDictで定義したpatch名と、各フィールドのboundaryFieldにあるpatch名を一致させる。

設定を確認したら、OpenFOAM 12のfoamRun workflowで解析する。

blockMesh
checkMesh
paraFoam

blockMeshとcheckMeshの後、paraFoamで計算前のメッシュとpatchを確認する。問題がなければ計算し、結果をParaViewで可視化する。

foamRun

必要に応じて計算後に渦度を生成する。

postProcess -func vorticity
paraFoam

角柱のケース構築は前章の手順を参考にする。

課題¶

自分で決めた2次元形状について、流れ解析を実施する。単純な形状は対象から除外する。

レポートには少なくとも次を含める。

  • 解析対象の形状と、形状を選んだ理由

  • 方眼紙または同等の方法で設計したblock構成

  • meshとpatchの定義

  • Reynolds数などの解析条件

  • 圧力場、速度場、その他の観察結果

提出方法と期限はKU-LMSで確認する。
