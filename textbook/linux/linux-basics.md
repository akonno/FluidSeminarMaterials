# Linux / UNIXコマンドラインの基本

Ubuntuの端末を開き、短いコマンドを実行しながら、コマンドラインの基本に慣れよう。

## shell、terminal、prompt

**terminal（端末）**は、文字を入力してコマンドを実行するための画面である。端末の中で入力を受け取り、コマンドを実行するプログラムを**shell**という。Ubuntuでは通常、bashというshellが使われる。

端末に表示される入力待ちの記号や文字列を**prompt（プロンプト）**と呼ぶ。promptの後ろにコマンドを入力し、Enterを押すと実行される。コマンドによっては、結果が端末に表示される。

CLI（文字による操作）では、実行する操作をコマンドとして入力する。GUI（画面上のボタンやアイコンによる操作）とは操作方法が異なるが、ファイルの確認やプログラムの実行など、同じ作業をどちらからも行える場合がある。

## コマンドを実行する

次のコマンドを一つずつ入力して、何が表示されるか確認する。

```bash
date
```

現在の日付や時刻が表示される。

```bash
cal 10 2022
```

カレンダーを表示する。月や年の指定を変えたときの違いも試してみよう。

```bash
cal 2022
cal 10
```

```bash
echo Hello
```

指定した文字列が端末に表示される。

```bash
yes
```

`yes`は同じ文字列を繰り返し出力する。動き続けるコマンドを止めるには、端末でCtrl+Cを押す。

```{admonition} 演習
:class: exercise

- `cal 10 2022`、`cal 2022`、`cal 10`の表示を比べ、指定の違いを説明する。
- 自分の誕生日が何曜日だったか、年を指定して調べる。
- `cal 9 1752`を実行する。この月の表示が特殊なのはなぜか、調べてみる。
- `yes`を実行し、Ctrl+Cで止める。
```

## ファイルとディレクトリ

Linuxでは、ファイルを入れる場所を**directory（ディレクトリ）**と呼ぶ。Windowsの「フォルダー」に相当する。コマンドを実行している場所を**current directory（カレントディレクトリ）**という。

次のコマンドで、現在の場所と、その中にあるファイルやディレクトリを確認できる。

```bash
pwd
ls
```

`pwd`は現在のディレクトリの場所を表示し、`ls`はその中身を一覧表示する。`cd`は作業場所を移動するコマンドである。

```bash
cd ..
pwd
cd ~
pwd
```

`..`は一つ上のディレクトリ、`~`は自分のホームディレクトリを表す。

**absolute path（絶対パス）**は、ルートディレクトリ`/`から始まる場所の表し方である。**relative path（相対パス）**は、カレントディレクトリを基準にした表し方である。同じファイルでも、現在の場所によって相対パスの書き方は変わる。

## 背景：UnixとLinux

Unixは1960年代末に開発されたオペレーティングシステムで、その設計や考え方は後の多くのシステムに影響した。POSIXは、Unix系のシステムで共通に利用できる機能や振る舞いを定めた標準の一つである。

LinuxはUnixそのものではなく、Unixに似た設計を持つOSのカーネルである。UbuntuなどのLinuxディストリビューションは、Linuxカーネルとコマンドやライブラリなどを組み合わせて提供される。macOSもUnix系の背景を持ち、端末で多くの共通したコマンドラインの考え方を利用できる。ただし、すべてのコマンドや動作が同一とは限らない。

研究・開発ではLinux環境を使うソフトウェアや計算機が多い。Windows上でWSLを使うことは、Linuxのコマンドやツールに慣れる一つの方法である。
