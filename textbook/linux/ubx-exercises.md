# UBXを使ったコマンド練習

UBXでは、Linuxコマンドを実際に実行し、その結果を使って課題に回答する。問題ごとに表示される指示を読み、端末内の作業を進めよう。

## UBXを起動する

Ubuntuの端末でUBX用仮想環境を有効にし、UBXを起動する。

```bash
source ~/venv-ubx/bin/activate
ubx
```

すでに同じ端末で仮想環境が有効になっている場合は、`source`の行を繰り返す必要はない。

## 1問に取り組む

UBXは課題の指示を表示し、`ubx$`のpromptがあるshellを開始する。指示に従ってLinuxコマンドを入力し、必要なファイルやディレクトリを扱う。コマンドの実行が終わり、作業内容を確認したら、そのshellで次を入力する。

```bash
exit
```

UBXに戻った後、質問が表示された場合は、作業結果をもとに回答する。判定が表示されたら、正解したかどうかを確認する。課題によって指示や質問は異なるので、まず問題文をよく読む。

## 初回の環境checkpoint

UBXを設定し、最低1問を正解するところまでを、導入時の環境checkpointとする。この一連の操作を通じて、WSL上で仮想環境を有効にし、UBXを起動して課題に取り組めることを確認する。

正解後は、UBXの状態を確認できる。

```bash
ubx --status
```

進捗はUBXのWeb側に記録され、教員はWeb UIで確認できる。専用の確認コードをKU-LMSへ提出する必要はない。`--status`には個人やクラスを識別できる情報が含まれる場合があるため、出力を共有するときは注意する。

このcheckpointはWSL / Python / UBXを使った練習の準備を確認するものであり、WSLgやGUIアプリが動作することを保証しない。GUIは[別ページのself-check](wsl-files-and-gui.md)として扱う。

## 続けて練習する

最初の1問を正解した後も、UBXを再実行して別の問題に取り組める。正解にならなかった場合は、表示された判定を確認して作業方法を見直し、必要に応じて`ubx`を再度起動して取り組む。

授業固有の提出物、締切、連絡事項がある場合はKU-LMSの案内に従う。UBXの進捗確認用コードを別途作成・提出する必要はない。
